Проект: MaxIDBot — бот для мессенджера MAX, выдающий ID сущностей (пользователь, чат, канал, бот, стикер)

В корне проекта лежит файл TZ.md — это полное техническое задание на проект. Изучи его внимательно от начала до конца, разберись в функциональных требованиях, API-эндпоинтах, структуре вложений и особенностях платформы MAX.

Дополнительно изучи документацию Max Bot API. Основной источник — dev.max.ru/docs-api и библиотека maxapi для Python на GitHub (max-messenger/max-botapi-python). Также изучи страницу dev.max.ru/docs/chatbots/bots-coding/prepare для понимания подготовки бота и dev.max.ru/docs/chatbots/bots-coding/library/js для понимания типов кнопок и структуры вложений. use context7

После изучения ТЗ и документации выполни следующее.

Создай проект со следующей структурой:

Корневая папка — max-id-bot. Внутри неё:

Файл TZ.md — техническое задание, уже лежит, не трогай его.

Файл bot.py — точка входа, инициализация Bot и Dispatcher, импорт и подключение всех обработчиков, запуск polling.

Папка handlers с файлом init, файлом start.py для обработки команды /start и события bot_started, файлом callbacks.py для обработки нажатий на четыре inline-кнопки (User, Chat, Channel, Bot) и файлом stickers.py для обработки входящих стикеров.

Папка keyboards с файлом init и файлом main_menu.py где определяется inline-клавиатура главного меню с четырьмя кнопками в сетке два на два: первый ряд — Chat и Channel, второй ряд — User и Bot. Все кнопки типа callback.

Файл config.py — загрузка токена из переменной окружения BOT_TOKEN через os.getenv.
