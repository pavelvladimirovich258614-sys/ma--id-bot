Изучи файл TZ.md в корне проекта — это полное техническое задание. Также изучи файл PROMPT_01_INIT.md — там описана структура проекта, которую нужно создать.

Дополнительно изучи актуальную документацию библиотеки maxapi для Python на GitHub (max-messenger/max-botapi-python), а также документацию Max Bot API на dev.max.ru/docs-api. Обрати внимание на типы событий, структуру inline-клавиатуры, типы кнопок и формат вложений. use context7

После изучения всех материалов создай полный рабочий скелет проекта по структуре из PROMPT_01_INIT.md. Но теперь не заглушки, а реальный рабочий код.

Начни с файла config.py — загрузка токена из переменной окружения BOT_TOKEN.

Затем файл keyboards/main_menu.py — определи inline-клавиатуру главного меню. Четыре кнопки типа callback в сетке два на два. Первый ряд: Chat с payload get_chat_id и Channel с payload get_channel_id. Второй ряд: User с payload get_user_id и Bot с payload get_bot_id. Используй эмодзи перед текстом каждой кнопки как в ТЗ.

Затем файл handlers/start.py — два обработчика. Первый на событие bot_started, второй на команду /start. Оба отправляют приветственное сообщение из ТЗ с inline-клавиатурой из main_menu.py.

Затем файл handlers/callbacks.py — обработчик события message_callback. Внутри проверяй payload. Если get_user_id — извлеки user_id, first_name, last_name, username из объекта user в событии и отправь ответ. Если get_bot_id — выполни запрос get_me и отправь информацию о боте. Если get_chat_id — извлеки chat_id из контекста и попробуй получить информацию о чате через API, отправь chat_id, название и число участников. Если get_channel_id — аналогично, но проверь наличие поля link чтобы определить что это канал, если ссылки нет — сообщи что нужно добавить бота в канал.

Затем файл handlers/stickers.py — обработчик события message_created. Проверяй наличие вложений типа sticker в сообщении. Если стикер найден — извлеки code, url, width, height и отправь пользователю информацию по формату из ТЗ.

Наконец файл bot.py — точка входа. Импортируй Bot и Dispatcher из maxapi, импортируй токен из config.py, подключи все обработчики из папки handlers и запусти polling.

Также создай файл requirements.txt с зависимостью maxapi и файл .env с шаблоном BOT_TOKEN=сюда_вставить_токен. Создай .gitignore с правилами для .env, pycache, venv. Создай README.md с кратким описанием и инструкцией: установка зависимостей через pip install -r requirements.txt, прописать токен в .env, запуск через python bot.py.

После создания всех файлов покажи дерево проекта и подтверди готовность к тестированию.
