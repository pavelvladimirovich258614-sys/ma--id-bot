# Методы API MAX

Источник: документация MAX API [3].

## Bots

Методы группы `bots` позволяют получить информацию о текущем боте. Обычно используется `GET`-метод для проверки токена, имени, ID и базовых свойств бота.

## Chats

Методы группы `chats` покрывают работу с чатами и каналами. В MAX канал может быть представлен как чат, поэтому при резолвинге важно учитывать дополнительные поля, например публичную ссылку.

Основные операции:

- `GET /chats` — получить список доступных чатов.
- `GET /chats/{chatId}` — получить информацию о чате или канале.
- `PATCH /chats/{chatId}` — частично обновить настройки чата.
- `DELETE /chats/{chatId}` — удалить или покинуть чат, если действие поддержано правами бота.
- `POST /chats/{chatId}/actions` — выполнить действие бота в чате.
- Методы pinned-сообщений — закрепление, получение и снятие закрепа.
- Методы администраторов — получение и управление администраторами, если у бота есть права.
- `GET /chats/{chatId}/members` — получить участников чата или канала.

Для Subscription Gate MaxIDBot использует `GET /chats/{chatId}/members` и ищет `user_id` в списке участников. Бот должен быть администратором канала.

## Subscriptions

Группа `subscriptions` используется для доставки событий боту:

- Webhook — рекомендуемый production-режим.
- Long polling — режим разработки и локального запуска.

В production следует использовать Webhook, чтобы MAX доставлял события на публичный HTTPS-endpoint.

## Upload

Группа `upload` используется для загрузки файлов:

- `POST`-методы загрузки принимают файл или метаданные файла.
- Загруженный файл затем может использоваться в сообщениях и вложениях.

## Messages

Группа `messages` отвечает за получение, отправку и изменение сообщений:

- `GET /messages/{messageId}` — получить сообщение по ID.
- `POST /messages` — отправить новое сообщение.
- `PUT /messages/{messageId}` — обновить сообщение, если операция поддержана.
- Методы callback — обработка нажатий inline-кнопок.

## Объекты

### User

`User` описывает пользователя MAX. Для MaxIDBot критичны поля с идентификатором пользователя, потому что они выводятся пользователю и применяются для проверки подписки.

### Chat

`Chat` описывает чат или канал. У каналов и публичных сущностей может быть ссылка, по которой можно отличать канал от обычного чата в логике резолвера.

### Message

`Message` содержит тело сообщения, автора, чат и вложения. В MaxIDBot используются обычные сообщения, пересланные сообщения и сообщения со стикерами.

## Клавиатуры

Inline-клавиатура передается в `attachments`. Лимит MAX: до 210 кнопок в 30 рядах.

Типы кнопок:

- `callback` — кнопка с payload для обработки ботом.
- `link` — кнопка-ссылка.
- `request_contact` — запрос контакта.
- `request_geo_location` — запрос геолокации.
- `open_app` — открытие мини-приложения.
- `message` — отправка предзаполненного сообщения.
- `clipboard` — копирование текста.

Для Subscription Gate нужна link-кнопка на `CHANNEL_LINK`.
