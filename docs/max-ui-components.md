# MAX UI Components

Источник: документация библиотеки MAX UI [4].

## Назначение

`@maxhub/max-ui` — React-библиотека компонентов для интерфейсов в экосистеме MAX. Она помогает создавать UI, который выглядит согласованно с клиентами MAX и поддерживает платформенные темы.

## Технологии

Библиотека рассчитана на:

- React 18+;
- TypeScript;
- современные сборщики фронтенда;
- использование CSS-переменных для настройки внешнего вида.

## Темы

MAX UI поддерживает темы iOS и Android. Это позволяет адаптировать внешний вид компонентов под окружение пользователя и сделать мини-приложение визуально ближе к нативному клиенту MAX.

## Полиморфные компоненты

Компоненты могут поддерживать паттерн `asChild`. Он позволяет отрисовать компонент поверх другого элемента, сохранив стили и поведение библиотеки.

Пример сценария: кнопка библиотеки может отрисовываться как ссылка, если нужно совместить семантику `<a>` и визуальный стиль кнопки.

## Кастомизация

Внешний вид настраивается через:

- CSS-переменные;
- обычные className;
- `innerClassNames` для настройки внутренних частей сложного компонента.

Для интерфейсов MAX важно не ломать ожидаемую визуальную структуру кнопок, списков и модальных элементов. Кастомизацию лучше делать точечно, сохраняя платформенные темы.
