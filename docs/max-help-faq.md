# FAQ MAX

Источник: справочная документация MAX [5].

## Регистрация

Раздел регистрации описывает создание аккаунта и базовый доступ к сервисам MAX. Для разработки ботов важно, что бот создается не просто из личного аккаунта, а через бизнес-контур.

## Организация

Для создания ботов требуется подтвержденная организация или индивидуальный предприниматель. Управление ботами и каналами выполняется через business.max.ru.

## Чат-боты

Раздел чат-ботов описывает создание бота, получение токена, интеграцию с API и ограничения платформы. Токен используется в заголовке авторизации и должен храниться как секрет.

## Каналы

Раздел каналов описывает публичные каналы, ссылки и администрирование. Для проверки подписки бот должен быть добавлен в канал с правами администратора.

## Мини-приложения

Мини-приложения запускаются внутри MAX и используют HTTPS URL, диплинки и клиентские возможности через Bridge. Они подходят для интерактивных сценариев поверх бота.

## События

События доставляются боту через Webhook или long polling. Для production предпочтителен Webhook, для разработки допустим long polling.

## Диплинки

Диплинки позволяют открыть бота или мини-приложение с payload. Payload должен быть коротким и безопасным: в него нельзя помещать токены, пароли или другие секреты.

## Поддержка

Раздел поддержки нужен для решения вопросов по бизнес-аккаунту, модерации, каналам, ботам и доступу к API.
